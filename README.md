# WorldWatch

Легкий настільний годинник-оверлей для Windows. Показує час (години:хвилини:секунди)
для кількох часових зон одночасно, завжди поверх інших вікон — як оверлей Steam, але
з секундами, кількома зонами та повним контролем вигляду.

Кожна часова зона — це **окреме незалежне прозоре вікно** зі своїми розміром,
кольором, прозорістю, шрифтом і позицією. Керування — через іконку в системному треї.

## Можливості

- Кілька годинників, по одному вікну на часову зону (стартово Нью-Йорк + Україна)
- Години / хвилини / секунди; формат 12 або 24 години
- Незалежні для кожного годинника: розмір цифр, колір, прозорість, шрифт, жирність
- Необовʼязкова текстова мітка поруч із часом (наприклад `NY 11:00:36`)
- Завжди поверх усіх вікон (topmost)
- Перетягування мишею + опція фіксації позиції
- Прихований з панелі задач і з перемикача **Alt+Tab** (tool window)
- Режим «На панелі задач»: усі видимі зони одним компактним блоком ліворуч від трею
  (`2026-10-31 NY 13:42:09`), з датою у форматі кожної зони; на панелях вибраних моніторів
- Автозапуск разом із Windows (перемикач у меню трею)
- Налаштування й позиції зберігаються між запусками
- Час береться із системного годинника Windows (уже синхронізованого через NTP) і
  конвертується через `TimeZoneInfo`, тому перехід на літній/зимовий час (DST)
  враховується автоматично

## Вимоги

- Windows 10/11
- [.NET 10 SDK](https://dotnet.microsoft.com/download) (для збірки)
- Готовий self-contained `.exe` (див. нижче) працює без встановленого .NET

## Збірка та запуск

Клонувати й запустити з вихідного коду:

```bash
git clone https://github.com/HoperUA/WorldWatch.git
cd WorldWatch
dotnet run
```

Або зібрати у режимі Release:

```bash
dotnet build -c Release
```

## Standalone .exe (без встановленого .NET)

Скачати .exe з GitHub https://github.com/HoperUA/WorldWatch/releases

Зібрати один самодостатній виконуваний файл:

```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Готовий `WorldWatch.exe` зʼявиться у:

```
bin/Release/net10.0-windows/win-x64/publish/
```

Його можна скопіювати куди завгодно й запускати подвійним кліком.

## Використання

Після запуску зʼявиться іконка в треї. Через її меню можна:

- показати/сховати кожен годинник;
- відкрити «Налаштування…» для годинника (зона, розмір, прозорість, колір, шрифт,
  формат 12/24, секунди, мітка, формат дати, фіксація позиції);
- увімкнути «На панелі задач» і вибрати, на панелях яких моніторів показувати блок;
- додати новий годинник з вибором часової зони;
- увімкнути/вимкнути автозапуск із Windows;
- вийти.

Перетягуй вікно годинника мишею, щоб змінити позицію (якщо позиція не зафіксована).
Подвійний клік по іконці трею показує/ховає всі годинники одразу.

Налаштування зберігаються у `%APPDATA%\WorldWatch\settings.json`.

### Режим «На панелі задач»

Блок не вбудовується в панель задач (Windows 11 не має для цього API), а лежить поверх
неї впритул до трею й сам пересувається, коли трей змінює ширину. Щоб він не закривав
кнопки програм:

- *Параметри > Персоналізація > Панель задач > Поведінка панелі задач >
  Об'єднувати кнопки панелі задач*: **Завжди**;
- щоб блок став на місце системного годинника, вимкни *Параметри > Час і мова >
  Дата й час > Показувати час і дату в області сповіщень*.

У блоці показуються годинники з увімкненим «Показувати»: мітка (або зміщення `UTC+2`,
якщо мітки немає), дата у форматі з налаштувань (за замовчуванням ISO `yyyy-MM-dd`,
порожньо: без дати) і час. Колір тексту йде за темою Windows. Коли відкрита
повноекранна програма, блок ховається разом із панеллю.

Монітори вибираються в меню трею «Монітори панелі задач» (за замовчуванням лише
основний). На панелях інших моніторів трею немає, тому блок стає ліворуч від кнопки
сповіщень. Якщо на вузькій панелі багато відкритих вікон, блок може закрити останню
кнопку програми: такий монітор краще не вибирати.

## Технології

WPF / .NET 10. Прозоре безрамкове вікно (`AllowsTransparency`), `Topmost`,
WinForms `NotifyIcon` для трею та `ColorDialog` для вибору кольору. Блок на панелі
задач позиціюється через Win32 (`TrayNotifyWnd`) і тримається над нею через
`EVENT_OBJECT_REORDER`.
